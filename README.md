# My First AI-Generated Flask App

## Project Description
This is my first Flask web application, created as part of the
Low-Code, No-Code & AI-Assisted Application Development course
at CCT College Dublin.

The application displays the message "Hello from Anastasiia"
on its home page.

## AI Tool Used
Google Gemini was used to generate the initial Python Flask
application and the requirements.txt file.

## Technologies
- Python
- Flask
- Git and GitHub
- Visual Studio Code

## How to Run
1. Download or clone this repository.
2. Create a Python virtual environment.
3. Activate the virtual environment.
4. Install dependencies using:
   pip install -r requirements.txt
5. Start the application using:
   python app.py
6. Open http://127.0.0.1:5000 in a browser.

## What I Learned
I learned how to use AI to generate Python code, install
dependencies, run a Flask application locally, and prepare
a project for GitHub.
